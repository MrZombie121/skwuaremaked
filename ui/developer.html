📖 СПЕЦИФІКАЦІЯ ПОЛІВ ВІДПОВІДІ (JSON SCHEMA)

ПАРАМЕТР ТИП ОПИС
id string Унікальний ідентифікатор цілі (напр. TGT-SH-101, TGT-MS-102).
type string Клас загрози: SHAHED, JET_UAV, MISSILE, BALLISTIC, KAB, AIRCRAFT, RECON, FPV, DECOY.
coordinates object Точні поточні GPS-координати цілі (lat: широта, lon: довгота).
location object Населений пункт виявлення (locality: місто/село, region: область).
target object Пункт призначення (destination, dest_lat, dest_lon, distance_km, eta_minutes).
flight object Параметри польоту (heading, heading_deg, speed_kmh, altitude, is_circling).
hazard_cone array Полігон небезпечного сектора підльоту (список координат [[lat, lon], ...]).
summary object Зведена статистика загрози у повітряному просторі за всіма типами.
